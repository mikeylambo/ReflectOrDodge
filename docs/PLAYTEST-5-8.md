# Playtest: Chapters 5–8

How to run: `npm run dev`, open `http://localhost:5173/?all=1` (every chapter unlocked). Chapter select → pick a room.

Every room below was solved by the solver and its recorded solution clears within par. What the solver can't tell us is whether a room *feels* right, so note anything that's:

- **Unclear**: you couldn't tell what the room wanted after a couple of tries.
- **Fiddly**: you knew the answer but the timing or position felt unfair.
- **Flat**: it plays the same as an earlier room.
- **Too easy**: especially pass rooms (◇0), which should still need you to time something.

◇ = the room's par (fewest answers). Pass = a room cleared without answering anything.
