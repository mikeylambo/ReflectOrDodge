# M0 report: Core feel

**Code commit:** `59d9a3e` on `claude/zealous-carson-gdeqkc` (this report is the next commit).
**HUMAN GATE:** passed. Mike played the three rooms and reported they "felt fluid". No tunables changed after the gate.

## Built

- Player: run (180 px/s), variable jump (64 px apex), coyote time (0.08 s), jump buffer (0.10 s).
- Reflect: 28 px zone, 0.20 s window, 0.25 s cooldown, 0.06 s hitstop. Four directions plus neutral, midair, and several projectiles per press.
- Projectile interface with a validator (purity, no input mutation, plain data), and the Orb.
- Objects: emitter (0.5 s telegraph; shuts off on a reflected hit), switch (once/toggle), door, exit, solid tiles, spike tiles (`^`), and breakable walls (light/heavy).
- Room JSON loader and validator: the GDD schema plus `solution`, `par`, `mirrorOf`.
- Instant reset on death and on R.
- Input recording and replay: per-frame masks in a compact run-length log. Any clear can be saved as the room's solution from the editor.
- Editor (`?edit=1`):
  - Paint tiles and spikes; place and link emitters, switches, doors, walls, spawn and exit.
  - Edit emitter period, phase and direction.
  - Play in the editor with P and return with the room untouched.
  - Timeline scrubber; save and load JSON through a dev endpoint; duplicate as a mirror room.
- Game feel table at placeholder fidelity:
  - Reflect arc on the held side; the projectile flashes white; tone pitched by direction; hitstop; gamepad rumble.
  - Target pulse and particle ring; lower tone on target hits.
  - Emitter charge glow with a rising tick.
  - Squash and stretch, jump afterimage, soft step.
  - Death burst in the killer's shape, 2 px shake, 0.15 s reset wipe.
  - Door slide with a light trail and a chord.
  - Room-clear ring from the exit and a resolving chord, 0.6 s before results.
  - Not built yet: the Examiner-defeat row (M2).
- Content: `p0-01` let it pass, `p0-02` reflect into a switch, `p0-03` return to sender.

## Tested, and how

`npm test`: 50+ checks, all passing at this commit.

- **Contracts:** every projectile and object module is checked against its interface.
- **Static guard:** `src/sim` contains no `Math.random`, clocks or timers.
- **Unit rules:** run speed, jump apex, jump cut, buffer, coyote, the five reflect directions, midair momentum, multi-catch counting, cooldown, hitstop, return-kill, law 1 (switches ignore the player), doors, emitter shut-off, telegraph timing, spikes, walls.
- **Room schema** for every room.
- **Determinism:** each solution replays twice in Node to an identical end-state hash, and Chromium's replay matches Node's hash.
- **Solutions:** each stored solution clears within par headlessly and through the live game session.
- **Browser smoke (Chromium via Playwright):** boots, renders, run, jump, reflect, R reset, 60 fps, editor boots, P toggles play, zero console errors.

## Not tested

- Gamepad and touch input on real devices (no hardware here). Touch is a placeholder layout.
- Audio is only checked for not crashing. Nobody has listened to it.
- Haptics on a Capacitor build; there is no native build yet.
